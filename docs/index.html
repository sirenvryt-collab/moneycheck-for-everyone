🍩 Donut Balance Tracker

Type /moneycheck to see how much your DonutSMP balance is up or down since midnight.

Download latest .jar

Setup

  1. Install Fabric Loader and the matching Fabric API for the Minecraft version this mod targets.
  2. Drop the downloaded jar into your .minecraft/mods folder.
  3. Join DonutSMP and type /moneycheck to see how much you're up or down since midnight. It tracks payment messages automatically.
  4. Optional: /moneycheck set 2.5M sets a starting balance so your total is tracked too.

How "since midnight" works

DonutSMP removed its API, so the mod reads payment chat messages instead. When someone pays you, the amount is added; when you pay someone, it's subtracted. The running total resets at your computer's local midnight and is saved to disk between sessions.
